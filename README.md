# MedSupply AI | Intelligent Medicine Shortage Prediction & Hospital Inventory Analytics

## Project Overview

MedSupply AI is a healthcare-focused Data Engineering and Machine Learning platform designed to analyze hospital medication inventories, forecast medicine demand, and identify potential drug shortages before inventory runs out.

The project integrates **Python, SQL, Scikit-learn, and automated ETL pipelines** to process synthetic hospital inventory and medication consumption data, calculate shortage-risk indicators, and generate demand forecasts.

## Business Problem

Hospitals face challenges managing essential medicine inventories due to unpredictable demand, supply chain disruptions, expiration dates, and limited inventory visibility.

These challenges can lead to medication shortages, inventory wastage, and increased operational costs.

## Project Objectives

- Develop automated data ingestion and ETL workflows.
- Process and validate medication inventory and historical consumption datasets.
- Predict future medicine demand using Machine Learning.
- Identify potential stockout risks.
- Generate SQL-based inventory analytics and reports.
- Evaluate forecasting accuracy and data processing reliability.

## Technologies Used

- **Programming:** Python, SQL
- **Data Engineering:** ETL/ELT, Data Validation
- **Machine Learning:** Scikit-learn, Random Forest
- **Database:** SQLite
- **Version Control:** Git, GitHub

## Data Engineering Architecture

Synthetic Hospital Data → Data Ingestion → Data Validation → ETL Processing → Inventory Analytics → ML Demand Forecasting → Stockout Risk Monitoring

## Key Features

### 1. Automated Data Processing
Processes synthetic hospital medicine inventory and daily consumption records through Python-based ETL workflows.

### 2. Machine Learning Forecasting
Uses a Random Forest model to forecast medication demand based on historical consumption patterns.

### 3. Medicine Shortage Risk Analysis
Evaluates inventory availability and consumption trends to identify potential stockout risks.

### 4. SQL Reporting
Generates structured inventory reports to support pharmacy supply planning.

### 5. Data Quality and Testing
Includes data validation and automated tests to improve pipeline reliability.

## Project Impact

Demonstrates how Data Engineering and Machine Learning can support proactive medicine inventory planning, shortage-risk identification, and healthcare supply chain analysis.

The project uses synthetic datasets and does not claim verified improvements in real hospital operations.
